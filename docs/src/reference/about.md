# About AgentForge

## Attribution

AgentForge is an AI agent development platform for building, evaluating, and deploying production agents under the Apache-2.0 license.

## Feedback

We value your input — it helps us improve AgentForge for the community.

- **Issues & suggestions:** [open an issue](https://github.com/Madhukar04012/AgentForge/issues) on GitHub
- **Share your experience:** reach out at [agents-cli@google.com](mailto:agents-cli@google.com)

## Contributing

The best way to contribute is through feedback: bug reports, feature requests, and ideas shared via [issues](https://github.com/Madhukar04012/AgentForge/issues) to directly shape our roadmap.
